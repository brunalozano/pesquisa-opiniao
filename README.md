# 📊 Programa de Pesquisa de Opinião

Este programa foi desenvolvido em **Python** com o objetivo de realizar uma pesquisa de satisfação com clientes de uma empresa, coletando nome, idade e a opinião de 50 entrevistados sobre o atendimento prestado, utilizando estruturas de repetição e decisão para contabilizar as respostas.

## 🐍 Tecnologias utilizadas

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![GitHub](https://img.shields.io/badge/GitHub-000?logo=github)

## ⚙️ Como funciona 

O programa solicita ao usuário o **nome do entrevistado**, a **idade do entrevistado** e a **opinião sobre o atendimento (1-EXCELENTE, 2-BOM, 3-RUIM)**. Em seguida, utiliza a estrutura de repetição **for** para realizar a pesquisa com os 50 entrevistados. Para contabilizar as respostas, é utilizada a estrutura de decisão **if**, que verifica a opinião informada. Ao final, o programa exibe a quantidade de respostas EXCELENTE e RUIM.

## ▶️ Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo `app.py`.
3. Clique no botão "Executar" localizado no canto superior direito do Visual Studio Code.
4. Digite o nome, a idade e a opinião sobre o grau de satisfação do atendimento quando solicitado.
5. Após as 50 respostas, o programa exibirá a quantidade de respostas EXCELENTE e RUIM.
